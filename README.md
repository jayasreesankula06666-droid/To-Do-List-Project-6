# Student To-Do List 📝

A beginner-friendly to-do list web app made with HTML, CSS, and JavaScript.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Automatically save tasks in browser local storage
- Responsive layout for mobile and desktop

## Project files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — task functionality and local storage

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

No installation or build step is required.

## Publish with GitHub Pages
1. Create a GitHub repository named `To-Do-List-Project`.
2. Upload all project files to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Note
Tasks are saved in the current browser on the current device. They do not automatically sync between devices.
